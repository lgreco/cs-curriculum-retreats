# cs-curriculum-retreats

Materials for the semiannual curriculum retreats of the Department of Computer
Science at Loyola University Chicago.

## Organization

Each retreat belongs in its own directory under `retreats/`. Keep that
retreat's agenda, notes, and other materials together in its directory. Each
retreat directory should also contain an `AGENTS.md` with instructions for
work specific to that retreat.

The repository-level `AGENTS.md` provides shared guidance for the
overarching agent. Retreat-level instructions supplement it and should focus
only on the retreat they accompany.
